# Claim registry for 0.9.0

Every claim used in the README top, the website (`site/index.html`), the social preview, the
release notes (`release-notes-0.9.0.md`), the technical article (`article.md`) and the posts must
be a row here. Each was re-run on 2026-10-17 between 00:20 and 00:40 UTC on the integration build
`f964a0f` (branch `sprint/f-launch`, packages still say `0.8.0` because the version bump happens
in `npm run release -- 0.9.0`), Node 22.17.1, macOS 26.5 on an Apple M2, after `npm run build`.
`hexvero` below means `node packages/cli/bin/hexvero.js`; the demo commands ran in an empty
scratch directory after `hexvero demo`.

Rule ([hexvero-launch-proof](../../.claude/skills/hexvero-launch-proof/SKILL.md)): a claim without
command, commit, date and limitation is a draft. Re-run a row before quoting it for another
version; after the release, run the same commands with `npx hexvero@0.9.0` from an empty cache.
