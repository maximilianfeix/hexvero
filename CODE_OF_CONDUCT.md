# Code of Conduct

hexvero follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep discussion about the work, and do not harass
anyone. This applies to issues, pull requests, discussions and every other project space.

Report unacceptable behaviour privately through
[GitHub's private vulnerability and conduct reporting](https://github.com/maximilianfeix/hexvero/security/advisories/new)
or by contacting the maintainer through their GitHub profile. Reports are handled confidentially;
the maintainer may remove content, warn, or ban, depending on severity.
